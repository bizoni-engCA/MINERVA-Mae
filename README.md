# Hackthon-NCE-Mulheres
Répositorio contendo os conteudos do Hackthon

## ESTRUTURA

- **Enfase em comunidade estudantil/universitária**
- Estilo de sub-comunidades para apoio, criadas por usuários pré aprovados para tal
- Aba de Informações com tipificações de forma a facilitar o entendimento da situação 
	- Aba como prosseguir
- Enfase em facilidade de denuncia e navegação
- Aba para gerenciamento de provas e criação de dossiê
- **Tem de haver uma equipe com foco e/ou especialidade na questão jurídica**
